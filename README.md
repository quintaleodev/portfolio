## 📂 Como rodar o projeto localmente

```bash
# Clone o repositório
git clone https://github.com/quintaleodev/portfolio.git

# Acesse a pasta
cd portfolio

# Instale as dependências
npm install

# Rode o projeto
npm run dev
```
